# Security Policy

## Supported Versions

This project is currently pre-1.0. Security fixes are applied to the latest
`main` branch.

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository, or by contacting the maintainer (@rahilsh) directly.

You can expect an initial response within a few days. Once a fix is prepared,
a coordinated disclosure will follow.
